trickle

Runtime type annotations for Python and JavaScript. Run your code, see every variable's type and value inline — in VSCode or in the terminal.

# install
pip install trickle-observe
npm install -g trickle-cli
code --install-extension yiheinchai.trickle-vscode

# run + inspect
trickle run python train.py
trickle hints
trickle vars

# Jupyter
%load_ext trickle

Use cases

ML Engineers

"I'm tired of printing tensor shapes everywhere."
%load_ext trickle in Jupyter, or trickle run python train.py. Tensor shapes appear inline in VSCode.
ML Engineer Guide →

Python Developers

"I don't know what this variable actually holds."
trickle run python app.py then trickle hints — types and crash-time values, no print statements.
Python Guide →

Data Scientists

"I'm tired of calling df.shape after every operation."
%load_ext trickle in Jupyter. DataFrames and Series show shape and dtypes inline.
Data Scientist Guide →

AI Agents

"I write correct code that fails on unseen data."
trickle hints and trickle hints --errors give runtime context in the terminal.
AI Agent Guide →

Get Started

Python / Jupyter

pip install trickle-observe
Then: trickle run python app.py or %load_ext trickle

CLI

npm install -g trickle-cli
Then: trickle hints / trickle vars

VSCode

code --install-extension yiheinchai.trickle-vscode
Inline type hints from .trickle/variables.jsonl
